# Модуль 1. Проект 3: Уровень дохода

Предсказываем, зарабатывает ли человек больше 50 000 долларов в год (`income`: `>50K` / `<=50K`) по данным переписи США (`adult.csv`, 32 561 человек).

**Заказчик:** банк решает, кому предложить премиальную кредитную карту. Предложение человеку с низким доходом даёт отказ и расходы на рассылку, пропуск человека с высоким доходом — упущенная выгода. Стоимость ошибок сопоставима.

## Файлы

| Файл | Что внутри |
|---|---|
| `project3_income.ipynb` | весь проект: блоки А (базовый), Б (основной), В (продвинутый) |
| `../data/adult.csv` | исходные данные (лежат в `Machine_Learning/data/`) |

## Как запустить

1. Положить `adult.csv` в `Machine_Learning/data/`.
2. Открыть `project3_income.ipynb` и выполнить `Kernel -> Restart & Run All`.
3. Нужны: `pandas`, `numpy`, `scikit-learn`, `matplotlib`, `seaborn`.

Ноутбук считается около 10–14 минут, больше всего времени занимает случайный лес в кросс-валидации. Случайность зафиксирована (`random_state=42`).

## Что сделано

- **А. Базовый:** `na_values="?"`, `info()`, пропуски и доли классов; `income` в 0/1; `train_test_split(test_size=0.2, stratify=y, random_state=42)` до любой обработки; `SimpleImputer(most_frequent)` для `workclass`, `occupation`, `native.country`; `OneHotEncoder` + `StandardScaler`; `LogisticRegression`, accuracy, confusion matrix. Модель нашла 61,7% людей с доходом >50K.
- **Б. Основной:** EDA (пропуски, скрытые «заглушки», выбросы, дубликаты, дублирующие признаки); `Pipeline` + `ColumnTransformer` без утечек; `LogisticRegression` и `RandomForest` на `StratifiedKFold(5)`; метрика F1 по классу `>50K` и подбор порога (0.38) по out-of-fold предсказаниям; итог на отложенном тесте (F1 0.729, recall 0.763).
- **В. Продвинутый:** таблица проблем данных и утечек; демонстрация утечки через ресемплинг до кросс-валидации; сравнение пяти методов против дисбаланса внутри CV; анализ ошибок по группам (пол, раса, возраст, семейное положение, образование, профессия); допустимость признаков для кредитного решения и ограничения.

## Главные решения

- Удалены `fnlwgt` (вес записи переписи, не признак человека) и `education` (дублирует `education.num`); проверено на кросс-валидации, качество не падает.
- Дубликаты удалены до разбиения на train/test.
- Порог и модель выбираются без участия теста, тест используется один раз в конце.
- `sex`, `race`, `native.country`, `marital.status`, `relationship` для кредитного решения использовать нельзя или спорно; без них ROC-AUC падает с 0.916 до 0.869.

## Ограничения

Данные 1994 года и из США, а не клиенты банка. Цель — доход, а не платёжеспособность. Стоимость ошибок банком не измерена, поэтому порог нужно пересчитать по реальным затратам. Подробности — в конце ноутбука.
